# Olymp Trainer

**ИИ-тренажёр для подготовки к олимпиадам по математике и физике.**
Номинация: *AI-Powered Solutions & Agents* (Software & AI Showcase, РФМШ Астана).

ChatGPT, Claude, Gemini и другие умеют решать задачи, но когда дело доходит до подготовки к олимпиадам, у них выявляются три основные проблемы:

1. **Они сразу выдают готовый ответ вместо подсказок по шагам, которые помогли бы ученику додумываться самому.** Ученик списывает ответ и не видит своего прогресса.
2. **Они ошибаются в придуманных задачах.** «Похожая задача» от искусственного интеллекта зачастую получается без решения или с бессмысленными числами.
3. **Они не помнят прогресс** и не знают, какие темы у ученика проседают.

## Чем мы отличаемся

| | ChatGPT / Claude / Gemini | Olymp Trainer |
|---|---|---|
| Новые задачи | Могут быть с ошибками | Ответы проверены кодом и сверены с независимым решением другой ИИ-модели |
| Помощь | Сразу дают ответ | Постепенные подсказки: намёк → идея → план → разбор |
| Физика | Размерность систематически не проверяется | Размерность важна: если спрашивали ускорение в м/с², а в ответе м/с, тренажёр это заметит и подскажет |
| Задачи | Источник не указывается | Оригинальные олимпиадные задачи с указанием олимпиады, года и ссылки, а для закрепления — их переформулированные варианты, с сохранением математической или физической идеи проверенные кодом |

## Как работает проверенное клонирование задачи

```
Олимпиадная задача + официальный ответ
        │
        ▼
 Gemini строит шаблон: параметры, ограничения, код-решатель
        │
        ▼
 Решатель в песочнице на исходных числах ── не совпал с официальным ответом? ──► отбраковано
        │ совпал ✓
        ▼
 Другая модель (Nemotron) решает 2 новых варианта ── расхождение? ──► помечено
        │ совпало ✓
        ▼
 Ученик получает сколько угодно вариантов, каждый с ответом,
 посчитанным кодом, а не «на глаз» языковой моделью
```

- Вариант полностью задаётся числом `seed`, поэтому его не нужно хранить: условие и ответ каждый раз восстанавливаются однозначно.
- Код-решатель, написанный ИИ, проверяется по списку разрешённых конструкций (без `import`, атрибутов, `eval`) и запускается в отдельном процессе с таймаутом и лимитом памяти.

## Олимпиады и этапы не смешиваются

Задачи сгруппированы в **треки**: одна олимпиада плюс один этап, например «Олимпиада Эйлера — региональный этап». В трек входят задачи этого этапа за разные годы.
Ученик выбирает трек, и список задач, темы и рекомендации берутся только из него. Задачи дистанционного и регионального этапа или разных олимпиад в одну подборку не попадают.

## Технологии

- **Бэкенд:** Python 3.12, FastAPI, SymPy (разбор выражений), SQLite.
- **ИИ:** Gemini API → OpenRouter (открытые модели NVIDIA Nemotron, Google Gemma). Если модель перегружена, запрос автоматически уходит следующей.
- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS 4, KaTeX (формулы).
- **Качество:** 120+ тестов (pytest, vitest), ruff, ESLint, GitHub Actions CI. В CI проверяется весь банк задач: каждый шаблон обязан воспроизводить официальный ответ.

```
backend/app/
  units.py      единицы и размерности (русские и латинские, приставки, степени)
  mathparse.py  безопасный разбор ответа: 2√3, 3/4, 1,5
  checker.py    проверка ответа + понятные сообщения об ошибке
  sandbox.py    песочница для кода-решателя
  cloner.py     генерация и проверка вариантов
  llm.py        цепочка моделей с переключением при сбое
  ai.py         подсказки, построение шаблонов, перекрёстная проверка
  scoring.py    баллы
  main.py       HTTP API
  tools/bank_tool.py  консольная утилита для банка задач
frontend/src/   интерфейс
```

## Запуск локально

Нужны Python 3.11+ и Node.js 20+.

```bash
# бэкенд
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env        # и вставьте ключи GEMINI_API_KEY / OPENROUTER_API_KEY
uvicorn app.main:app --reload
```

```bash
# фронтенд (в другом терминале)
cd frontend
npm install
npm run dev                 # http://localhost:5173
```

Тесты: `cd backend && pytest`, `cd frontend && npm test`.

## Деплой

Один Docker-контейнер (фронтенд + API), см. `Dockerfile`. На Render: New → Web Service → репозиторий → Docker, переменные окружения `GEMINI_API_KEY` и `OPENROUTER_API_KEY`.

## Источники задач

Ученик решает оригинальную задачу, а затем закрепляет материал на её переформулированных вариантах с другими числами.
Оригиналы взяты из открытых архивов олимпиад и сайтов с задачами, у каждой задачи указан источник со ссылкой. Проект некоммерческий и учебный. Если правообладатель попросит убрать задачу, мы её уберём.
