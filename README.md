# Olymp Trainer

**ИИ-тренажёр для подготовки к олимпиадам по математике и физике.**
Номинация: *AI-Powered Solutions & Agents* (Software & AI Showcase, РФМШ Астана).

ChatGPT и Claude умеют решать задачи, но для подготовки к олимпиадам у них три проблемы:

1. **Они сразу дают ответ.** Ученик списывает и ничему не учится.
2. **Они ошибаются в придуманных задачах.** «Похожая задача» от ИИ часто получается без решения или с бессмысленными числами.
3. **Они не помнят прогресс** и не знают, какие темы у ученика проседают.

## Чем мы отличаемся

| | ChatGPT / Claude | Olymp Trainer |
|---|---|---|
| Новые задачи | Могут быть с ошибками | **Проверены кодом**: решатель воспроизводит официальный ответ, а другая модель независимо решает варианты |
| Помощь | Сразу ответ | **Лестница подсказок**: намёк → идея → план → разбор |
| Физика | Размерность не проверяется систематически | **Анализ размерности**: «у тебя получилась длина, а спрашивают время» |
| Источники | Нет | Реальные олимпиадные задачи с указанием олимпиады и года |
| Мотивация | — | Баллы вместо ярлыков «лёгкая/сложная», рейтинг, карта навыков |

## Как работает проверенное клонирование задачи

```
Олимпиадная задача + официальный ответ
        │
        ▼
 ИИ (Gemini) строит шаблон: параметры, ограничения, код-решатель
        │
        ▼
 Решатель в песочнице на исходных числах ── не совпал с официальным ответом? ──► отбраковано
        │ совпал ✓
        ▼
 Другая модель (Nemotron) решает 2 новых варианта ── расхождение? ──► помечено
        │ совпало ✓
        ▼
 Ученик получает сколько угодно вариантов, каждый с ответом,
 посчитанным кодом, а не «на глаз» языковой моделью
```

- Вариант полностью задаётся числом `seed`, поэтому его не нужно хранить: условие и ответ восстанавливаются детерминированно.
- Код-решатель, написанный ИИ, проходит белый список конструкций (без `import`, атрибутов, `eval`) и запускается в отдельном процессе с таймаутом и лимитом памяти.

## Баллы

- Стартовые баллы задачи зависят от этапа олимпиады, класса и номера задачи.
- Дальше цена подстраивается по статистике (байесовское сглаживание): если задачу решают почти все, она дешевеет, если почти никто — дорожает.
- Подсказки: −20% / −40% / −60%. После разбора за оригинал баллов нет, а новый вариант стоит 50%: так разбор превращается в тренировку, а не в списывание.
- Процент решивших показывается **только после решения**, чтобы не пугать заранее.

## Технологии

- **Бэкенд:** Python 3.12, FastAPI, SymPy (разбор выражений), SQLite.
- **ИИ:** Gemini API → OpenRouter (открытые модели NVIDIA Nemotron, Google Gemma). Если модель перегружена, запрос автоматически уходит следующей.
- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS 4, KaTeX (формулы).
- **Качество:** 115+ тестов (pytest, vitest), ruff, ESLint, GitHub Actions CI. В CI проверяется весь банк задач: каждый шаблон обязан воспроизводить официальный ответ.

```
backend/app/
  units.py      единицы и размерности (русские и латинские, приставки, степени)
  mathparse.py  безопасный разбор ответа: 2√3, 3/4, 1,5
  checker.py    проверка ответа + понятные сообщения об ошибке
  sandbox.py    песочница для кода-решателя
  cloner.py     генерация и проверка вариантов
  llm.py        цепочка моделей с переключением при сбое
  ai.py         подсказки, построение шаблонов, перекрёстная проверка
  scoring.py    баллы
  main.py       HTTP API
  tools/bank_tool.py  консольная утилита для банка задач
frontend/src/   интерфейс
```

## Запуск локально

Нужны Python 3.11+ и Node.js 20+.

```bash
# бэкенд
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env        # и вставьте ключи GEMINI_API_KEY / OPENROUTER_API_KEY
uvicorn app.main:app --reload
```

```bash
# фронтенд (в другом терминале)
cd frontend
npm install
npm run dev                 # http://localhost:5173
```

Тесты: `cd backend && pytest`, `cd frontend && npm test`.

## Деплой

Один Docker-контейнер (фронтенд + API), см. `Dockerfile`. На Render: New → Web Service → репозиторий → Docker, переменные окружения `GEMINI_API_KEY` и `OPENROUTER_API_KEY`.

См. [docs/PROBLEM_FORMAT.md](docs/PROBLEM_FORMAT.md). Сейчас в банке демо-задачи, составленные командой. Реальные олимпиадные задачи добавляются с указанием источника.

## Авторские права

Задачи берутся из открытых официальных архивов олимпиад, у каждой указан источник. Варианты переформулированы и содержат другие числа. Разборы пишутся заново. Проект некоммерческий и учебный. Если правообладатель попросит удалить задачу, мы её удалим.
