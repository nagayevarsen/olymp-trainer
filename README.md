# Olymp Trainer

**ИИ-тренажёр для подготовки к олимпиадам по математике и физике.**
Номинация: *AI-Powered Solutions & Agents* (Software & AI Showcase, РФМШ Астана).

Сайт: **https://olymp-trainer.onrender.com** (исходный код открыт, сайт работает без регистрации в GitHub).

ChatGPT, Claude, Gemini и другие умеют решать задачи, но когда дело доходит до подготовки к олимпиадам, у них выявляются три основные проблемы:

1. **Они сразу выдают готовый ответ вместо подсказок по шагам, которые помогли бы ученику додумываться самому.** Ученик списывает ответ и не видит своего прогресса.
2. **Они ошибаются в придуманных задачах.** «Похожая задача» от искусственного интеллекта зачастую получается без решения или с бессмысленными числами.
3. **Они не помнят прогресс** и не знают, какие темы у ученика проседают.

## Чем мы отличаемся

| | ChatGPT / Claude / Gemini | Olymp Trainer |
|---|---|---|
| Задачи | Источник не указывается | 1111 оригинальных олимпиадных задач с указанием олимпиады, этапа, года и ссылки на официальный архив |
| Ответы | Модель может ошибиться и не скажет об этом | Ответ взят из официального решения; если решения нет — подтверждён несколькими моделями и программой |
| Новые варианты | Могут быть с ошибками | Ответ каждого варианта считает код, проверенный на официальном ответе |
| Помощь | Сразу дают ответ | Постепенные подсказки: намёк → идея → план → разбор |
| Физика | Размерность систематически не проверяется | Если спрашивали ускорение в м/с², а в ответе м/с, тренажёр это заметит и подскажет. Ответ можно дать формулой — она проверяется символьно |
| Прогресс | Не помнят | Решённые задачи, баллы, серия дней, слабые темы, рейтинг |

## Что умеет тренажёр

- **Задачи по трекам.** Трек — одна олимпиада плюс один этап, например «Олимпиада Эйлера — региональный этап». Задачи разных олимпиад и этапов не смешиваются.
- **Олимпиада на время.** Пробный тур с официальной длительностью и баллами (только там, где время взято из официального документа, `backend/app/olympiad_rules.py`).
- **ИИ-помощник в чате.** Подбирает задачи, разбирает решение ученика, не выдаёт ответ сразу. Отвечает Claude Haiku; если задача трудная и он не уверен, вопрос уходит более сильной модели Claude Sonnet. Вычисления помощник проверяет кодом. Если не может решить надёжно — честно об этом говорит. Во время пробной олимпиады только уточняет условие.
- **Рисунки к задачам** вырезаются из официальных PDF и показываются на сайте, а также передаются ИИ вместе с условием.
- **Проверка ответа:** числа (`2√3`, `3/4`, `1,5`), единицы измерения, формулы с переменными.

## Как проверяется ответ задачи без официального решения

```
Задача из официального архива (без ответа)
        │
        ▼
 Три модели разных производителей решают её независимо,
 две модели пишут программы (перебор, численный счёт) — программы запускаются в песочнице
        │
        ▼
 Программы совпали между собой и с большинством решений? ── нет ──► задача не попадает в банк
        │ да ✓  (спорные случаи дополнительно решает Claude Sonnet)
        ▼
 В банк, с пометкой origin: verified и списком, чем подтверждён ответ
```

На 31 задаче с известным ответом проверка не приняла ни одного неверного ответа.

## Как работает проверенное клонирование задачи

```
Олимпиадная задача + официальный ответ
        │
        ▼
 ИИ строит шаблон: параметры, ограничения, код-решатель
        │
        ▼
 Решатель в песочнице на исходных числах ── не совпал с официальным ответом? ──► отбраковано
        │ совпал ✓
        ▼
 Модель другого производителя решает 2 новых варианта ── расхождение? ──► помечено
        │ совпало ✓
        ▼
 Ученик получает сколько угодно вариантов, каждый с ответом,
 посчитанным кодом, а не «на глаз» языковой моделью
```

- Шаблоны есть у 295 задач.
- Вариант полностью задаётся числом `seed`, поэтому его не нужно хранить: условие и ответ каждый раз восстанавливаются однозначно.
- Код-решатель, написанный ИИ, проверяется по списку разрешённых конструкций (без `import`, атрибутов, `eval`) и запускается в отдельном процессе с таймаутом и лимитом памяти.

## Технологии

- **Бэкенд:** Python 3.12, FastAPI, SQLite, SymPy (формулы).
- **ИИ:** Claude Haiku 5.5 и Sonnet 5.5 (Anthropic) — чат, проверка решений, импорт задач. Gemini и открытые модели через OpenRouter — лестница подсказок и независимая перекрёстная проверка ответов.
- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS 4, KaTeX (формулы). Service worker кэширует сайт; без интернета показывается экран «Нет интернета».
- **Безопасность:** вход по токену сессии, хранится только хэш пароля; пароли от 8 символов, без простых и утёкших (проверка Have I Been Pwned по k-анонимности); лимиты на вход, регистрацию, ответы и запросы к ИИ.
- **Качество:** pytest (≈ 2900 проверок, включая проверку каждой задачи банка), vitest, ruff, ESLint, GitHub Actions CI.

## Запуск локально

Нужны Python 3.12 и Node.js 22.

```bash
# бэкенд
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env        # вставьте OLYMP_ANTHROPIC_API_KEY (и по желанию GEMINI_API_KEY / OPENROUTER_API_KEY)
uvicorn app.main:app --reload
```

```bash
# фронтенд (в другом терминале)
cd frontend
npm install
npm run dev                 # http://localhost:5173
```

Тесты: `cd backend && pytest`, `cd frontend && npm test`.
