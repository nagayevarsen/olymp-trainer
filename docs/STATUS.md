## Безопасность и ИИ в чате (6 ноября)

- Вход по токену сессии (`Authorization: Bearer`), id пользователя секретом не является; выход отзывает
  токен. Старые входы без токена не работают — ученикам нужно войти заново.
- Лимиты: вход — 10 неудачных попыток на ник за 15 минут; новые аккаунты — 40 в час с адреса;
  ответы — 15 попыток на задачу за 10 минут; ИИ — 60 сообщений на ученика в день и 3000 на сервер.
  На Render нужно задать `TRUST_PROXY=1`. Все настройки — в `backend/.env.example`.
- Ответы ученика считаются в float с проверкой переполнения (`999^999^999` больше не вешает сервер).
- Чат: отвечает Haiku. Если задача трудная и он не уверен (или не успел ответить), он передаёт вопрос
  Sonnet (`claude-sonnet-5-5`) — не больше 5 раз в день на ученика и 150 на сервер. Ответ Sonnet ≈ $0.02–0.03.
  В олимпиаде на время Sonnet не подключается.

## Beyond Olympiads (6 ноября)

- Республиканская олимпиада (Казахстан): республиканский, областной и районный этапы; юниорская олимпиада;
  Қазақстан Білім Олимпиадасы. Манифесты — `backend/data/imports/kz-*.json`.
- Файлы с решениями: ответ должен быть в официальном PDF. У физики в PDF решений нет условий —

- Файлы без решений: ответ подтверждён проверкой (Haiku + Sonnet/Nemotron + программа), `origin: verified`.
  Это дорого: ≈ $0.13 за принятую задачу. Сделаны республиканский и областной этапы по математике
  (частично — остановились на лимите), районный этап и физика без решений — не сделаны.
- Все новые задачи просмотрены вручную; негодные и повторы удалены.

## Импорт задач

```bash
cd backend
python -m app.tools.bank_tool discover <страница сайта>          # найти PDF
python -m app.tools.bank_tool import-manifest data/imports/X.json  # импорт партии
python -m app.tools.bank_tool check                               # проверка банка
```

`bank_tool import-manifest` берёт задачи с числовым ответом без рисунка, и ответ должен
буквально встречаться в официальном PDF. Задачи с рисунками и ответами-формулами — пока только
IZhO по физике (`python -m app.tools.izho_physics`). Брать файлы с решениями: в файлах только с условиями
ответов нет. Задача из нескольких пунктов делится на отдельные задачи (общее условие + пункт);
пункт без общего условия (в файле только решения) отбрасывается.
PDF внутри ZIP: адрес `https://site/archive.zip#member=dir/file.pdf`.

Модель для импорта: переменная `IMPORT_MODEL` (например `anthropic:claude-haiku-5-5`,
ключ — `OLYMP_ANTHROPIC_API_KEY` или `ANTHROPIC_API_KEY`;
в облачной среде Claude Code `ANTHROPIC_*` вырезаются, там нужен `OLYMP_ANTHROPIC_API_KEY`).
Без неё используются бесплатные модели Gemini по кругу (у них маленькие дневные квоты).
`--parallel 2–4` — больше Claude начинает отвечать «превышен лимит запросов».

## Проверка ответов без официального ключа (`app/verify.py`, `app/methods.py`)

- Три модели разных производителей решают задачу независимо; две модели пишут программы
  (перебор / численный счёт по графику / перебор графов), программы выполняются в песочнице.
- Принимается, только если программы совпали между собой и с большинством решений.
  Если дешёвые модели не договорились — подключается Sonnet 5.5 как ещё один голос.
- Для больших чисел: перебор маленьких случаев + формула из банка методов (94 формулы и теоремы,
  каждая формула в тестах сверяется с перебором — `tests/test_methods.py`).
- Калибровка (`bank_tool verify-eval`) на 31 задаче с известным ответом: **0 неверно принятых**,
  15 принято верно, 16 отклонено (13 из них — бесплатные Gemini/Nemotron были недоступны, не хватило голосов).
- Ответ с `answer.origin = "verified"` хранит в `verified_by`, чем подтверждён. В интерфейсе пока не показывается.
