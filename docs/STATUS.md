## Импорт задач

```bash
cd backend
python -m app.tools.bank_tool discover <страница сайта>          # найти PDF
python -m app.tools.bank_tool import-manifest data/imports/X.json  # импорт партии
python -m app.tools.bank_tool check                               # проверка банка
```

В банк попадают только задачи с числовым ответом без рисунка, и ответ должен
буквально встречаться в официальном PDF. Брать файлы с решениями: в файлах только с условиями
ответов нет. Задача из нескольких пунктов делится на отдельные задачи (общее условие + пункт);
пункт без общего условия (в файле только решения) отбрасывается.
PDF внутри ZIP: адрес `https://site/archive.zip#member=dir/file.pdf`.

Модель для импорта: переменная `IMPORT_MODEL` (например `anthropic:claude-haiku-5-5`,
ключ — `OLYMP_ANTHROPIC_API_KEY` или `ANTHROPIC_API_KEY`;
в облачной среде Claude Code `ANTHROPIC_*` вырезаются, там нужен `OLYMP_ANTHROPIC_API_KEY`).
Без неё используются бесплатные модели Gemini по кругу (у них маленькие дневные квоты).
`--parallel 2–4` — больше Claude начинает отвечать «превышен лимит запросов».

## Проверка ответов без официального ключа (`app/verify.py`, `app/methods.py`)

- Три модели разных производителей решают задачу независимо; две модели пишут программы
  (перебор / численный счёт по графику / перебор графов), программы выполняются в песочнице.
- Принимается, только если программы совпали между собой и с большинством решений.
  Если дешёвые модели не договорились — подключается Sonnet 5.5 как ещё один голос.
- Для больших чисел: перебор маленьких случаев + формула из банка методов (40 методов,
  каждая формула в тестах сверяется с перебором — `tests/test_methods.py`).
- Калибровка (`bank_tool verify-eval`) на 31 задаче с известным ответом: **0 неверно принятых**,
  15 принято верно, 16 отклонено (13 из них — бесплатные Gemini/Nemotron были недоступны, не хватило голосов).
- Ответ с `answer.origin = "verified"` хранит в `verified_by`, чем подтверждён. В интерфейсе пока не показывается.

   (ВсОШ заключительный по физике: 1 задача из 36 файлов). Нужно вырезать рисунок из PDF.

5. ВсОШ — остальные этапы и годы с 2010: `vsosh-*-all.json` (≈ 520 файлов, ≈ $4).
