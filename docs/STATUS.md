# Статус работы и следующие шаги

Памятка для продолжения работы (в том числе в новой сессии).

## Что уже сделано

- Приложение: бэкенд (FastAPI) + фронтенд (React), CI на GitHub Actions.
- Банк задач: ~350 задач. Источники только из `backend/data/sources.json` (49 проверенных сайтов).
  - «Курчатов» — заключительный и отборочный этапы 2021–2026, все классы (`data/imports/kurchatov.json`).
  - IZhO — математика и теоретическая физика 2010–2024 (`data/imports/izho.json`).
  - 26 задач «Курчатова» 7 класса занесены вручную, с проверенными ответами.
- Треки: олимпиада + этап. Разные олимпиады и этапы не смешиваются.

## Импорт задач

```bash
cd backend
python -m app.tools.bank_tool discover <страница сайта>          # найти PDF
python -m app.tools.bank_tool import-manifest data/imports/X.json  # импорт партии
python -m app.tools.bank_tool check                               # проверка банка
```

В банк попадают только задачи с числовым ответом без рисунка, и ответ должен
буквально встречаться в официальном PDF.

Модель для импорта: переменная `IMPORT_MODEL` (например `anthropic:claude-haiku-5-5`,
ключ — `OLYMP_ANTHROPIC_API_KEY` или `ANTHROPIC_API_KEY`;
в облачной среде Claude Code `ANTHROPIC_*` вырезаются, там нужен `OLYMP_ANTHROPIC_API_KEY`). Без неё используются бесплатные модели Gemini по кругу
(у них маленькие дневные квоты).
