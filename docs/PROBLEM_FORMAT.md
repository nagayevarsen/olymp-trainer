# Как добавить задачу

Каждая задача лежит в отдельном файле `backend/data/problems/<id>.json`.
Имя файла должно совпадать с `id` (латиница, цифры, `-`, `_`).

Задачи с одинаковыми `source.olympiad` и `source.stage` образуют один **трек**, годы могут быть разными.
Разные этапы и разные олимпиады — это разные треки, в приложении они не смешиваются.

## Минимальная задача (без вариантов)

```json
{
  "id": "resp-2024-9-3",
  "subject": "physics",
  "topic": "Кинематика",
  "title": "Короткое название",
  "statement": "Текст условия. Формулы в LaTeX: $v = \\frac{s}{t}$.",
  "answer": { "value": 4, "unit": "с" },
  "source": {
    "olympiad": "Республиканская олимпиада",
    "year": 2024,
    "stage": "republic",
    "grade": 9,
    "number": 3,
    "url": "https://... (ссылка на официальный архив)"
  }
}
```

| Поле | Что писать |
|---|---|
| `subject` | `math` или `physics` |
| `topic` | Тема по-русски. Пишите одинаково во всех задачах: «Кинематика», а не то «Кинематика», то «кинематика» |
| `answer.value` | Ответ числом. Дроби можно десятичными: `2.5` |
| `answer.unit` | Единицы для физики: `м/с`, `кДж`, `Ом`, `км/ч`… Для математики не пишите |
| `answer.rel_tol` | Допустимая погрешность. По умолчанию 1% для физики, точное совпадение для математики |
| `source.olympiad` | Название олимпиады. Пишите **одинаково** во всех задачах этой олимпиады: по нему задачи собираются в один трек |
| `source.stage` | `school` (школьный), `distance` (дистанционный), `city` (городской), `region` (региональный/областной), `republic` (республиканский), `final` (заключительный), `international`, `other` |
| `points` | Не обязательно: баллы считаются сами по этапу, классу и номеру задачи |
| `solution` | Не обязательно: разбор. Если его нет, ИИ напишет свой |

В JSON обратный слэш удваивается: `\\frac`, `\\cdot`.

## Подсказки и шаблон для вариантов делает ИИ

После добавления задач запустите из папки `backend`:

```bash
python -m app.tools.bank_tool templates    # ИИ делает шаблоны для вариантов
python -m app.tools.bank_tool crosscheck   # другая модель независимо решает варианты
python -m app.tools.bank_tool hints        # ИИ пишет лестницу подсказок
python -m app.tools.bank_tool check        # итоговая проверка всего банка
python -m app.tools.bank_tool preview resp-2024-9-3   # посмотреть 3 варианта
```

Шаблон сохраняется в файл задачи, только если его решатель **воспроизводит
официальный ответ**. Подсказки тоже сохраняются в файл: **прочитайте их и
поправьте руками**, если что-то сформулировано неудачно.

## Как устроен шаблон (если хотите написать его сами)

```json
"template": {
  "text": "Мяч бросили вверх со скоростью {v} м/с ... $g = {g}$ м/с².",
  "params": { "v": { "min": 5, "max": 45, "step": 1 }, "g": { "value": 10 } },
  "original": { "v": 20, "g": 10 },
  "solver": "def solve(v, g):\n    return 2 * v / g\n",
  "constraints": ["answer > 0"],
  "answer_integer": false,
  "answer_max_decimals": 1
}
```

- `params`: диапазон `min..max` с шагом `step` или фиксированное `value`.
- `solver`: функция на Python. Доступны `sqrt, sin, cos, pi, gcd, lcm, comb, factorial, pow, …`, без `import`.
- `constraints`: условия, при которых вариант имеет смысл. Можно использовать параметры и `answer`.
- `answer_integer` / `answer_max_decimals`: в вариант попадают только «красивые» ответы.
