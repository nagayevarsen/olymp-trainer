## Правила (действуют всегда)

- Задачи берём только с сайтов из `backend/data/sources.json`.
- Олимпиады и этапы не смешиваем: одна партия импорта = одна олимпиада + один этап.
  Этап и год берём из структуры страницы или адреса файла, никогда не угадываем.
- Официальное время тура и баллы — только с источником (`backend/app/olympiad_rules.py`).
  Нет официального времени — режима «олимпиада на время» для неё нет.
